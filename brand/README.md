# Samay LLC logo

Script set in Corinthia Bold, with "LLC" in Inter SemiBold. Both fonts are under the SIL Open Font License, which allows logo use. Every file is outlined (vector paths), so no fonts need to be installed.

| File | Use |
|---|---|
| `samay-square-256.png` / `-512` / `-1024` | Square logo, transparent (invoices, e.g. Mercury) |
| `samay-square-white-*.png` | Square logo on white |
| `samay-square-dark-*.png` | Square logo on dark (profile pictures) |
| `samay-llc-horizontal[-light].svg/-2000.png` | Wide logo with LLC, dark or light ink |
| `samay-wordmark[-light].svg/-2000.png` | Script "Samay" only |
| `samay-icon.svg/-512.png/-1024.png`, `favicon-32.png`, `apple-touch-icon.png` | "S" icon |

Colors: ink `#16161a`, light `#f5f5f6`, dark background `#111113`.
